========================================
FRRO Form C Desktop Auto-Fill Setup Guide
========================================

This sets up a local server that automatically fills Form C on
indianfrro.gov.in. You only solve the CAPTCHA — everything else
is automated.

========================================
PREREQUISITES
========================================

1. Install Node.js (v18 or higher)
   Download from: https://nodejs.org
   
   Verify installation:
   node --version
   npm --version

2. Install Git (if not already installed)
   Download from: https://git-scm.com

========================================
SETUP - macOS
========================================

# Open Terminal and run:

git clone https://github.com/thegokosocial/GokoHostelWebpages.git ~/Downloads/GokoWeb
cd ~/Downloads/GokoWeb/scripts
npm init -y && npm install playwright express cors sharp
npx playwright install chromium
echo 'alias frro="cd ~/Downloads/GokoWeb && npx tsx scripts/frro-server.ts"' >> ~/.zshrc
source ~/.zshrc

# To start the server, type:
frro

========================================
SETUP - Linux (Ubuntu/Debian)
========================================

# Open Terminal and run:

git clone https://github.com/thegokosocial/GokoHostelWebpages.git ~/GokoWeb
cd ~/GokoWeb/scripts
npm init -y && npm install playwright express cors sharp
npx playwright install chromium
npx playwright install-deps chromium
echo 'alias frro="cd ~/GokoWeb && npx tsx scripts/frro-server.ts"' >> ~/.bashrc
source ~/.bashrc

# To start the server, type:
frro

========================================
SETUP - Windows
========================================

# Open PowerShell and run:

git clone https://github.com/thegokosocial/GokoHostelWebpages.git C:\GokoWeb
cd C:\GokoWeb\scripts
npm init -y && npm install playwright express cors sharp
npx playwright install chromium

# Add shortcut (paste this into PowerShell):
echo 'function frro { cd C:\GokoWeb; npx tsx scripts/frro-server.ts }' >> $PROFILE

# Close and reopen PowerShell, then type:
frro

========================================
HOW TO USE
========================================

1. Open terminal and type: frro
   (Server starts at http://localhost:3456)

2. In the admin panel, open a foreign guest's Form C

3. Click "Desktop: Auto-Submit"

4. A browser window opens with FRRO login page
   - Username and password are pre-filled
   - YOU solve the CAPTCHA and click Sign In

5. After login, the script automatically:
   - Uploads passport photo (resized to <50KB JPG)
   - Navigates to Form C
   - Fills all fields
   - Clicks "Temporary Save and Exit"

6. Done! Check FRRO site to review and submit permanently.

========================================
TROUBLESHOOTING
========================================

Error: "Executable doesn't exist"
  → Run: npx playwright install chromium

Error: "Local server not running"
  → Open terminal and type: frro

Error: "Login timed out"
  → Solve the CAPTCHA within 2 minutes

Fields not filling:
  → Check terminal for "NOT FOUND" messages
  → Use "Mobile: Copy Script" as alternative
  → Or fill manually using the Edit view in Form C modal
